# Show task keys in a dependency change as code

A revision that changes the dependencies of a task shows the raw keys:

`Dependencies: +SIN-9 −SIN-10`

Render each key with the code component instead of plain text, and keep the `+` and `−` marks so an added key and a removed key still read apart.
